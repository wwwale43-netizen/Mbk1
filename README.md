# نموذج تأييد مبادرة ملتقى الحوار السياسي الليبي–الليبي

نسخة ثابتة باللغة العربية وبتخطيط من اليمين إلى اليسار، أُعيد إعداد ملفاتها القابلة للتحرير اعتمادًا على المحتوى والملفات العامة الظاهرة في الموقع المنشور:

- الموقع المرجعي: https://libyaform-fd7gxjee.manus.space/
- الوثيقة المرفقة: `assets/initiative-document.pdf`
- صورة الهوية: `assets/initiative-icon.png`

## هيكل المشروع

```text
.
├── index.html                 # محتوى الصفحة، النموذج المعطّل، وإشعار الخصوصية
├── styles.css                 # تخطيط RTL والتصميم المتجاوب
├── assets/
│   ├── initiative-icon.png    # صورة الهوية المنشورة
│   └── initiative-document.pdf
└── README.md
```

## التشغيل محليًا

لا يحتاج المشروع إلى إطار عمل أو تثبيت حزم. من مجلد المشروع شغّل:

```bash
python3 -m http.server 8000
```

ثم افتح http://localhost:8000.

## حدود النسخة

- هذه إعادة بناء لملفات الواجهة من الصفحة المنشورة، وليست استعادة للمستودع الأصلي أو ملفات المصدر الأصلية.
- النموذج **معطّل عمدًا**: لا يوجد خادم أو قاعدة بيانات أو نقطة API، ولا تُحفظ أو تُرسل بيانات المشاركين.
- لا تفعّل استقبال التأييدات قبل إعداد التخزين والحذف الآمنين، واختبارهما، ومراجعة إشعار الخصوصية ومصدر المبادرة.
- النصوص المتعلقة بالجهة المسؤولة أو التكليف أو الإيداع نُقلت من المواد المنشورة؛ وجودها هنا لا يعني التحقق المستقل منها.
- لا يوجد ملف ترخيص مضاف؛ لم يُفترض ترخيص للمحتوى أو للوثيقة.
